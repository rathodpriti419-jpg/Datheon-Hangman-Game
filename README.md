# Hangman Game Using Python

## Project Introduction
The Hangman Game is a simple word-guessing game developed using Python.

## Project Features
- Random word selection
- Guess one letter at a time
- Six incorrect attempts
- ASCII hangman drawings
- Tracks guessed letters
- Prevents duplicate guesses from reducing attempts
- Displays winning and losing messages

## Technology Used
- Python 3
- Random module

## How to Run
1. Install Python 3.
2. Download the project.
3. Open the terminal in the project folder.
4. Run `python hangman.py`.
